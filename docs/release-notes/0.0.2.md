Nothing in the app has changed since 0.0.1.

This release exists to exercise updating itself. 0.0.1 shipped with the
machinery — Sparkle, a signed feed, a notarized DMG — but a first release has
nothing to update *from*, so none of it could be proven. 0.0.2 is the first
version an installed copy can actually find, download, verify and install, and
these notes are the first ever carried inside the feed.

If you are reading this in Shellhand's own update window, every part of it
worked.
