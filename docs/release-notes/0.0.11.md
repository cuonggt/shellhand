**The host list answers the mouse the way you would expect.** Clicking a host
opens the panel on the right showing what it connects with, instead of leaving
you to go and find it. Two clicks connect. And a right-click gives the same
menu the sidebar's rows have always had — connect, SFTP, copy the ssh command,
edit, delete — acting on the host you clicked rather than on whatever happened
to be selected before.

**The keyboard reaches the list too.** Arrow keys walk it, whether it is
drawn as rows or as cards, and Return connects to the host that is picked. A
key pressed there no longer draws a ring around the whole panel to say the
list is listening; the highlighted host already says it.

**A file dropped from Finder that could not be carried said nothing about
it.** Dropped onto a folder you have no permission to write in, or a disk with
no room left, the file stayed where it was and the window gave no sign that
anything had gone wrong — while the same copy made by dragging between the two
panes has always reported it. Both say so now.

Nothing else here is visible from the outside. The suite went from 479 checks
to 495.
