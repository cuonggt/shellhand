**The host editor shows its command the way the inspector does**, one
argument a line, with a long one wrapping under itself. It was the line you
would paste into a shell, cut to two lines, so a host behind a jump host
showed a run of quote marks with its middle missing. A long command scrolls in
a box of its own, and the editor is a little taller to make room for it.

**New Host says why Add is greyed out.** It said nothing until something was
typed, while New Group warned that a group needs a name before anything had
been typed at all. Both now say what is missing from the start, quietly, and
warn only once you have begun.

**The import's "Put new hosts in" looks like a field.** It sat against the
right edge of its row, where "optional group" read like a group already
chosen. It is a box beside its label now, like every other field.

**The SFTP window no longer counts what is not there.** While its right side
was still asking which host to show, that side said "0 items", which reads as
an empty folder, and This Mac's button said "Copy to Choose a host". The side
with nothing in it counts nothing now, and the button says Copy.

**Quick Connect knows a host you have saved.** Typing the address of a host
already in your list showed the typed row as "Not in your list", right under
that host. It now says "As typed, without web's settings" — web being the
saved host — since connecting as typed leaves that host's key, jump host and
options behind.

**Hide Beside says what it does.** With a tab shown beside the one in front,
the Terminal menu's ⌘D item still said Show Beside, though pressing it closed
the split. It says Hide Beside then.

Nothing else here is visible from the outside. The suite went from 756 checks
to 759. With these, everything the walk through the whole window after 0.1.4
found is fixed.
