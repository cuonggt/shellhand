**A terminal keeps 10,000 lines of history.** It kept 500 — SwiftTerm's own
default — so a log or a long build scrolled out of reach within a few
screens, and Find could only search what was left. Raising it waited on
something else: every ssh session read its whole screen five times a second,
history and all, to watch for a host-key question, which already cost a
session up to 6% of the main thread at 500 lines and would have cost far more
at 10,000. A session now reads its screen only while it is connecting, while a
question is up, and for two minutes after it comes through, which covers every
hop of a jump chain. After that, a host-key question asked by something you
run inside the session — an `ssh` typed there, `git` over ssh — is answered in
the terminal itself, as in Terminal.app, rather than through Shellhand's
dialog.

**Shellhand asks a host what it runs only while you let it.** Asking is a
second login, once a day per host, and on a machine with login alerts or a
session recorder that is something somebody sees. Settings ▸ General has a
Hosts section now, with a switch that turns the asking off. It starts on, as
asking always has, and turning it off keeps the marks already learned.

**Report a Problem opens a form.** Help ▸ Report a Problem… opens a new issue
on a form that asks what happened and what you expected, with the versions of
Shellhand and macOS already filled in. Questions and ideas have a place of
their own now, in the repository's Discussions.

**A settings file Shellhand cannot use says so now, and so does an import.**
A mistake in `config.yaml` — an unclosed quote, a setting spelled wrong, an
option ssh would refuse — left Shellhand running without the file, its ssh
options and palettes quietly not applied, and a YAML import with a mistake in
it came in as an empty list. Neither said a word, in any release so far. Now
the window says what is wrong with the settings file when it opens, the import
refuses the file with its reason, and a YAML mistake comes with its line and
column. The settings file is read when Shellhand opens, so a fix takes effect
the next time it does.

Nothing else here is visible from the outside. The suite went from 622 checks
to 643, the history's size was measured before it was chosen — about 8 bytes
a column for each line, so 8 to 16 MB a session at 10,000 lines — and the
settings file's message was checked on screen, against a copy of the app with
a broken file of its own.
