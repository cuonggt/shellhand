**⌘W closes the tab again, not the window.** Since 0.1.3, ⌘W went to the
system's own Close rather than Shellhand's Close Tab, so it closed the whole
window. With a session still running it asked about the window; with nothing
running it closed the window and every tab in it without a word. ⌘W closes
the tab in front again, asking first while its session is still running, and
closes SFTP or Settings when one of them is in front.

**A session that is still connecting says so.** A warning ssh prints before it
reaches the host — a key file that is not there is the usual one — made the
session read as connected: its tab went green and Stop Connecting greyed out
while ssh was still trying. Those warnings no longer count as the host
answering, so the session stays connecting, with its time and Stop
Connecting, until something does.

**Show Beside fits the window.** Showing a tab beside the one in front widened
the window past the edge of the screen, cutting off the right-hand side and
pushing the inspector out of reach. The two sides now share the width the
window has, half each to begin with, and the line between them can be
dragged.

**An import leaves your hosts where you filed them.** The group typed into
"Put new hosts in" was given to every host the file left unfiled, including
ones already in your list, so importing your ssh config a second time with a
group typed moved hosts out of the groups you had put them in. It now files
only the hosts the import adds.

Nothing else here is visible from the outside. The suite went from 746 checks
to 753. A walk through the whole window after 0.1.4 found all four of these,
and the window check now fails if ⌘W belongs to anything but Close Tab.
