**Picking a host no longer takes the list away.** Clicking a host used to
replace the whole list with that host's details, so you could never click down
a list of machines — the one you had just picked was the only one you could no
longer see. The list stays now, with the host you picked highlighted, and what
it connects with appears in a panel on the right. Arrow keys walk the list and
Return connects, so a machine three rows down is three keys away.

**And the list stays where you left it.** Looking inside a group and picking a
host there used to widen the list back to every host you have, moving the row
out from under the pointer. Where you are looking and what you have picked are
two different things now: a group is somewhere to go, a host is something to
choose. Picking a host in the sidebar that is filed somewhere else brings the
list to it, so what is selected is always something you can see.

The panel on the right is the one the button at the end of the toolbar has
always opened, and it now carries the whole of a host: the address, the user,
the key and the jump host — each saying where it was inherited from — the ssh
command that will actually run, and the sessions already open on that machine.
It opens by itself the first time; the same button shuts it again, and it
stays however you leave it.

Nothing else here is visible from the outside. The suite went from 466 checks
to 479, and the one check that drives a real window now reads the list and the
panel as well as the sidebar.
