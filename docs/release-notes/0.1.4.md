**Renaming a host takes what goes through it along.** A host that others
jumped through, named in their Through field or in a group's, left them
naming a machine no longer in the list once it was renamed, and ssh was left
to find one by that name on its own. Saving a new name now rewrites every
host's and group's Through field that named the old one, and the editor says
what will follow before you save — "6 hosts and the groups EU and US go
through bastion, and will follow the new name."

**The window opens with the keyboard in the host list.** macOS gave it to the
search field, the window's first text field, so ↓ and Return did nothing
until the list was clicked. Now the arrows walk the list and Return connects
from the moment the window opens. ⌘F still goes to the search.

**A host called bastion is no longer offered itself to jump through.** The
Through field's grey example was "bastion" on every host, which on a host
called bastion read as the loop Shellhand refuses to save. There it suggests
"gateway" instead.

Nothing else here is visible from the outside. The suite went from 737 checks
to 746, and the README's picture and shellhand.com show the window as it is
now, where they showed an older one.
