**A folder from a host arrived without its empty folders.** Dragging a folder
from a host onto this Mac carried every file in it, but none of the folders
that held nothing — and dragging an empty folder brought nothing across at
all, while the transfer said it had finished. Every folder arrives now, empty
or not, and a folder sent up and brought back is the folder it was.

**A host-key question in a narrow window could go unasked.** With large text,
or a window narrow enough, ssh's question about a new machine's key wraps
across several lines of the terminal. Past two of them it was not seen, so
ssh sat waiting for an answer the app never asked you for. It is asked now
however many lines it takes, and the dialog shows the whole question,
fingerprint included.

**Answering a host-key question could bring it back for an instant.** In the
moment between your answer and the terminal showing it, the question could
reappear — and a click in that moment typed into the shell. An answered
question stays answered.

Nothing else here is visible from the outside. The suite went from 448 checks
to 459, and folders are now among what it carries for real against OpenSSH's
own server: the first fix above was found the first time anything tested a
folder at all.
