First release.

A native macOS SSH client: the host list, tabs on real `ssh`, and files over
SFTP, in a window.

- **The host list.** Hosts filed in groups, with the user, the key and the jump
  host inherited down the tree, and a detail pane that shows the exact `ssh`
  command a host will run and where each value came from. Found by tag as well
  as by name — several tags at once, narrowing.
- **Tabs on real `ssh`.** Each tab is its own connection on its own pty, not a
  multiplexed session. Five terminal palettes ship and the settings file can
  add more; a group can set the colours for everything beneath it, so
  production need not look like staging.
- **Files over SFTP**, beside a pane for this Mac. Transfers queue a couple at
  a time rather than all starting at once, and carrying a file onto one
  already there asks first.
- **Import and export.** Reads `~/.ssh/config`, a CSV, or this app's own YAML,
  with a dry run before it applies anything. Exports YAML meant for a dotfiles
  repository — it names things rather than carrying ids, and holds no secrets.

Requires macOS 26. Universal, signed and notarized. Updates from here are
delivered in the app.

**One known limitation.** A host that logs in with a password only works in a
terminal tab, where `ssh` asks on the pty and you type it. SFTP cannot reach
such a host at all: its child process is given `BatchMode=yes`, and there is
nothing to answer a prompt with. Hosts that use a key are unaffected.
