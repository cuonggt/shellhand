**Quick Connect reaches machines that are not in your list.** Type
`user@host:port` into ⌘K — or `host`, `host:port`, `[v6]:port`, or paste an
`ssh://` link — and the palette offers to connect to it as typed, under "Not
in your list". A host you have saved still comes first when what you typed
names it exactly, so its key and its jump host still apply; an address, or a
destination with a user or a port, comes next, ahead of saved hosts that
merely contain it; and a bare word is still a search, its own row last.
Nothing typed this way is saved, and ⌘R and ⌘T work on it like on any other
session.

**The tabs answer the keys every other Mac app gives them.** ⇧⌘] and ⇧⌘[
move to the next and the previous tab, and so do ⌃⇥ and ⌃⇧⇥, going round
from the last to the first and taking in the Hosts tab on the way. ⌘T opens
another session like the one in front — to the same machine, or another
local shell — where it used to open whatever the list had selected, which
need not have been the machine you were looking at. With the Hosts tab in
front it still opens the host selected.

**A tab has a menu of its own.** Right-click one for Reconnect, Duplicate,
SFTP, Close Tab and Close Other Tabs, each acting on the tab you clicked
rather than the one in front. Reconnecting or closing a session that is still
running asks first, exactly as ⌘R and ⌘W do, and closing the others asks
once for all of them.

**The terminal's font is yours to choose.** Settings ▸ Terminal has a Font
picker now: SF Mono, as before, or any monospaced font installed — a Nerd
Font for a prompt that draws its own glyphs included — with a line of sample
text drawn in it, so it is chosen by looking. Open sessions change at once
and keep the size they are at, and Actual Size keeps the font rather than
going back to SF Mono. A font that is no longer installed falls back to SF
Mono rather than leaving a terminal in one it cannot draw.

**⌥⌘K clears the scrollback.** Clear Scrollback, in the Terminal menu, drops
everything above the screen and keeps what is on it — vim or less in front
included — on the key Terminal.app gives it. ⌘K stays Quick Connect.

**Export and Help are where you would look for them.** File ▸ Export… writes
your list as YAML, where it used to be found only inside the Import window.
The Help menu opens the README, and Report a Problem… opens a new issue
already holding the version and the macOS it came from — and nothing else.

**The host panel no longer breaks an address in two.** The line saying where
a host goes — `deploy@203.0.113.21 port 2222` — sat beside Edit and Connect
in whatever room they left, and wrapped inside the address. It has a full
line of its own now, and one too long even for that is shortened in the
middle, whole on its tooltip.

Nothing else here is visible from the outside. The suite went from 570 checks
to 622, and the tab keys were also pressed on a copy of the app on screen,
each moving the tab in front.
