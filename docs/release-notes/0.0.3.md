**⌘B brings the SFTP window back.** It used to do nothing whenever the host
list was not the front window — including from the SFTP window itself and from
Settings, which is exactly when you would reach for it. Bringing a browser you
already have forward no longer needs the host list in front. Opening a *new*
one still does, because that needs the host list the window holds.

Nothing else is visible from the outside. The rest of this release is
groundwork: the rules behind the tab strip, Quick Connect's ranking, the group
tree and the host store have been lifted into places that can be checked
without driving the window, and the suite went from 254 checks to 315 — the
first of them to reach above the engine. Three cycle guards, against a group
becoming its own ancestor, had never been exercised until now.

The Release build compiles without a warning again, which is mostly worth
saying because that is where a real one would otherwise hide.
