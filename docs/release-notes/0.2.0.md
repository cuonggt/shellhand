**The window no longer crashes at its narrowest.** Dragged as narrow as it
goes, the host window aborted on the first group picked in the sidebar — 0.1.7
and every release before it. The middle column held no width of its own, so
what it showed moved its minimum, and picking a group asked a window already
at its narrowest to widen in the middle of a layout pass, which AppKit ends by
throwing. The column now holds one width whatever it shows, so no selection
can move it. You reached it by dragging the window right in; the window as it
opens was never there.

**Sheets fit the window they open over.** At the default window size, 0.1.7's
host editor hung below the bottom edge with Save under it. The editors and the
import are now no taller than the room under the toolbar, and where that is
less than they want, the host editor's command box gives way first — but only
by what the form can spare, read off the form as drawn, so the rows keep their
room. Settings opens as tall as its tallest pane, where General's last section
and Terminal's Keyboard sat wholly below the edge, and the palette picker fits
the window it opens over wherever a palette is chosen.

**The host list survives a narrow pane.** Every row now drops the same thing at
the same width — its tags first, then its group — where each row chose for
itself, so one host kept a tag beside the next host losing the same tag. The
name column is as wide as the longest name in the list rather than a fixed 240,
which at the default size stood mostly empty while every row gave up its tags;
cards are 210pt at their narrowest, so two fit across the pane as it opens,
where one column of wide cards left their words in the left quarter; and a card
keeps its line of group and tags whether or not anything is on it, so a row of
cards stands one height.

**A group picked in the host pane is selected, not opened.** Arrowing onto one
replaced the list under the highlight, so ↓ could never get past the first
group. It is selected now, and two clicks or ⏎ open it. The pane and the
sidebar also agree about what they are counting: the sidebar heads its tree
Groups, as the pane does, and the whole list counts every group as it counts
every host, where "12 hosts, 2 groups" was said of four.

**The tab strip shares its room by what each name needs.** Short names give
their spare width to long ones, down to a floor, before the strip scrolls —
shared evenly, "This Mac — ~" was cut to "This…c — ~" with 65pt of the strip
standing empty. A name too long for its share is cut in the middle and at its
dots, never beside one, where "root@127.0.0.1:2" read "root@….0.1:2" and
"127.0.0.1:2" read "127….1:2"; a second tab's number stays whole after it; an
edge with tabs past it fades, where the first tab was shown sheared with
nothing to say the strip scrolled; the tab in front scrolls back into view
whenever the strip's width changes; and a tab's tooltip is its whole name,
where it was the shell's own title. A local shell's tab says This Mac, as the
inspector and SFTP call it, and the title bar says what the tab says.

**The inspector describes a machine typed into ⌘K, and a local shell.** It said
"Nothing selected" for both, so a machine reached through Quick Connect could
not be saved from anywhere in the window. A typed machine now has its address
written as a listed host's, port and all, What will run, Open now listing the
tabs on that same machine, and Save as Host…; a local shell has Open now with
the shells on this Mac and which of them is in front. A host's Open now marks
each tab as the strip does, where a tab that never connected was listed as open
as a live one, and says In front on the one already there.

**A host SFTP cannot open says what it means and what to do.** The refusal is
drawn as the terminal's card for the same failure — the headline red with its
mark, ssh's own line boxed and first, the way on leading — where it was plain
text with the retry last, so one failure looked like two different things in two
windows. Every failure now offers Edit Host… as a terminal tab does, and Try
Again reads the host from the list afresh, where it went again with the copy
the side was pointed at and a host renamed in Edit Host… kept its old name.

**An SFTP side with nothing in it asks for a host.** While the right side was
still waiting to be pointed somewhere it said "0 items", which reads as an
empty folder, and drew an empty striped table under a sortable header. It asks
for a host now, alone on the table's ground, and the other side's button says
Copy rather than "Copy to Choose a host". A side re-pointed while it is still
connecting opens where it points now, and what the first connection brings back
is closed on arrival.

**Controls that were live and did nothing are greyed out.** In the SFTP window:
a side's path field and its "…" menu while it lists nothing, ↑ at "/", Edit ▸
Delete with nothing selected, and New Folder's Create and Rename's button for a
name they would refuse — they took one, closed the question and did nothing.
New Folder also says where the folder goes, since ⇧⌘N acts on whichever side
last had the keyboard. With SFTP in front the menu bar names its own keys:
File's New Folder… and View's Refresh, with Reconnect giving ⌘R up.

**One setting has one name, and an inherited value reads value first.** Settings
called the terminal's palette Palette under a header saying Colours, which is
where an inspector's "System from Settings" sent you; it is Colours everywhere
now. Agent forwarding reads "Carried from Production", or "Not carried by
default" where nothing says, in both editors and both inspectors — the host
inspector had no row for it at all — where it read "From Production — carried".
A palette is chosen by looking at it everywhere one is chosen, through the same
swatch and picker, where three places offered a menu of names. And no field's
example names a host, group, user, key or tag that is in your list, where
"bastion" in Production's Jump host read as Production going through it.

**The import says one thing about your SSH config.** What the file holds was
said three ways in three places, two of them at once, and a config naming no
machine was reported as no file at all. The path typed in has its `~` expanded,
where the field's own example found nothing; the file is spelled "SSH config"
wherever the app names it; and each tab is headed by the name and the line the
welcome gives that source. Export… greys out with nothing to export and says a
save the disk refuses, where it wrote an empty file and dropped every refusal
without a word.

**Every deletion question ends the same way.** Delete Group… left out "This
cannot be undone.", which every other one says, and said all of a group's hosts
move to the top of the list — they land in Ungrouped, at its foot, and the
groups inside it each become a group of its own, which is what the sidebar and
the editors call those places.

Nothing else here is visible from the outside: Settings' own layout, the
session cards drawn as one shape on the window's own ground, the palette
swatch, the editors' captions standing in one column, and a long tail of
alignment. Two walks through the whole window after 0.1.7 found all of it. The
suite went from 759 checks to 806.
