**The menus offer only what works.** With the SFTP window or Settings in
front, New Host…, New Group…, New Local Shell, Import… and Quick Connect…
were enabled and did nothing, and so was Shellhand ▸ SFTP with nothing to open
it from. Reconnect was live on a local shell, which has no host to reconnect
to. They grey out now. macOS's own window tabs are gone from View and Window,
where they offered a tab bar and a second pair of tab items on the strip's own
keys. And two tabs on the same host each get a ⌘ number of their own in the
Window menu — "refuser" and "refuser (2)" — where both landed on one.

**Deleting a group says what really happens.** It said all of a group's hosts
moved to the top of the list, when only the ones filed in it directly do: the
groups inside it move up with their own hosts still in them. It says so now,
and says that what the group gives those hosts — the user, the key, the
palette — goes with it.

**The palette picker fits in Settings.** It was taller than the Settings
window, which left its Done button below the window's edge. It now fits the
window it opens over.

**The SFTP window opens with the keyboard in This Mac's list**, as the host
window opens in its host list, rather than in the path field, where ↓, Space
and ⌫ edited the path.

**The host editor speaks like the rest of the app.** Its inherited values say
"from Production", as the group editor and the inspector do, and the settings
it called Through and Agent are Jump host and Agent forwarding, as they are
everywhere else.

Nothing else here is visible from the outside. The suite went from 753 checks
to 756.
